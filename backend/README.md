# Backend (FastAPI)

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
pip install -r requirements.txt
copy .env.example .env
```

Make sure [Ollama](https://ollama.com) is installed and running:

```bash
ollama serve
ollama pull llama3.1
```

## Run

```bash
uvicorn app.main:app --reload
```

API docs (auto-generated by FastAPI) at http://localhost:8000/docs.

## Layout

- `app/main.py` — app entrypoint, CORS, router registration
- `app/core/config.py` — settings from env vars (see `.env.example`)
- `app/models/schemas.py` — all request/response models
- `app/routers/` — HTTP endpoints (thin — validate + delegate to services)
- `app/services/` — actual logic (Ollama client, MIDI analysis, audio analysis, lyrics)

## Current status

Every route exists and is wired end to end, but the feature-specific services
(`midi_analysis.py`, `audio_analysis.py`, `lyrics_lab.py`) raise `NotImplementedError` until their
phase is built — see [../PLAN.md](../PLAN.md). Hitting those endpoints currently returns
`501 Not Implemented`. `services/ollama_client.py` is already functional.
